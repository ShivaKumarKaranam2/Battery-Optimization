# AI Battery Optimization

A comprehensive AI-powered battery optimization system for electric vehicles.

## Project Structure

```
AI_BATTERY_OPTIMIZATION/
├── AI-battery/         # Java backend with ML models (XGBoost, RUL, SoH calculators)
└── ev-battery-frontend/ # React + TypeScript frontend for visualization
```

## Components

### AI-battery
- Java Spring Boot application with battery ML services
- XGBoost-based prediction models
- Telemetry normalization and validation
- Vehicle document parsing and service integration

### ev-battery-frontend
- React + TypeScript + Vite frontend
- Battery health dashboard
- Charging optimization interface
- Vehicle management and telemetry visualization
